Read before using

  • Trained on two Portuguese secondary schools in 2005 and 2006 (UCI Student Performance data, Cortez and Silva, CC BY 4.0). It's a teaching project, not a tool for decisions about real students.
  • Sex, age, home address, whether parents live together and dating status are left out. In cross-validation the model without them was just as accurate.
  • Same model as the R and Shiny app: an elastic net trained with tidymodels, exported to plain numbers and run here in JavaScript. Code at github.com/evannwilsonn/earlybird.
